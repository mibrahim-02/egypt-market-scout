# bkam y 3mo — بكام يا عمّو

Cute phone-first GitHub Page that asks **bkam y 3mo?** across Egyptian e-commerce.

**Live page:** https://mibrahim-02.github.io/egypt-market-scout/

## Open on iPhone

1. Open the link in **Safari**.
2. Tell her what you're buying: `ايفون 15`, `air fryer`, `غسالة`.
3. Optional: Share → **Add to Home Screen**.
