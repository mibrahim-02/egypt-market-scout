# قارن مصر — Egypt Market Scout

A phone-first GitHub Page that compares a product across **Egyptian** e-commerce sites. Type the name in Arabic or English.

**Live page:** https://mibrahim-02.github.io/egypt-market-scout/

## Open on iPhone

1. Open the link in **Safari** (not Chrome, if you want Add to Home Screen).
2. Search any product: `ايفون 15`, `air fryer`, `غسالة فوق أوتوماتيك`.
3. Optional: Share → **Add to Home Screen** so it opens like an app.

## What it compares

Egypt-only stores, including Jumia Egypt, Amazon.eg, Noon Egypt, B.TECH, 2B, Raneen, Carrefour Egypt, Tradeline, Raya, Homzmart, Vodafone shop, Pricena Egypt, Prime Tech, and Dubizzle (used).

Results are ranked by **price**, **rating**, or **review count**. International marketplaces (Temu, AliExpress, Amazon.com, Noon UAE/KSA, Jumia Nigeria, etc.) are filtered out.

## Notes

Prices are read from public search snippets and product pages. Some stores use bot protection, so a listing may open in Safari even when a live price could not be extracted. Always confirm the price on the store before buying.
